# Public Release Gates

This public leaf is derived from a private consulting workspace. The public
copy is intentionally generic and does not include filled client deliverables.

## Gates

- License: MIT license included.
- Secret: run `ctk-validate templates examples`.
- Claim: avoid unverified personal metrics or customer claims.
- Privacy: keep contact, payment, and client details as placeholders.
- Test: run `python -m pytest`.

## Release Checklist

- [ ] Templates use bracketed placeholders.
- [ ] No private contact details.
- [ ] No payment account identifiers.
- [ ] No client names, customer data, or signed terms.
- [ ] Validator and tests pass.
